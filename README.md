# MachineLearningProject Portfolio
> Built by Micheal Olatunji Okanlawon — Physics Graduate | ML Engineer in Training

## About
A machine learning project for exploring and building predictive models using Python.

## Projects

### 1. Student Academic Performance Prediction
Predicts students' final grades (G3) using regression and classification models.
- **Dataset:** UCI Student Performance Dataset
- **Models:** Linear Regression, Decision Tree, KNN, Random Forest
- **Highlights:** Leakage-aware preprocessing, F1 score evaluation, confusion matrix analysis
- **Status:** ✅ Complete

---

### 2. Chicago Taxi Fare Prediction
Predicts taxi fares from a large real-world dataset using a Keras neural network.
- **Dataset:** Chicago Taxi Trips
- **Models:** Keras Regression Neural Network
- **Highlights:** Feature scaling, learning rate tuning, MAE optimisation
- **Status:** ✅ Complete

---

### 3. Atmospheric AI — Climate-Driven Signal Reliability Framework
Physics-informed ML framework modelling how atmospheric water vapour affects
radio signal propagation in Abuja, Nigeria.
- **Dataset:** ERA5 Climate Data (2015–2024)
- **Models:** LSTM, Physics-Informed Neural Network (PINN)
- **Highlights:** Decade-long meteorological analysis, ITU-R model comparison
- **Status:** 🚧 In Progress
